Read methodology
How many startup jobs are listed on JobPin?
As of 2026-09-30, 10662 active startup roles from 807 companies across 7 countries and 818 cities. Listings are refreshed daily from each company's public ATS.
Which countries does JobPin cover?
Open roles are currently tracked in United States (7381), Germany (1141), United Kingdom (571), France (174), India (170), Canada (86), Singapore (51), with emerging coverage in Sweden, Spain, Netherlands, Saudi Arabia, Italy, Australia, Ireland, Latvia.
Where does the jobs data come from?
Directly from each company's public ATS API (Greenhouse / Lever / Ashby / Workable / SmartRecruiters / Recruitee / Personio), refreshed daily. Every role links to the original posting — we do not proxy applications or store applicant data.
Is JobPin free to use?
Yes. Browsing every company, job, ranking and guide is free, and each role links straight to the employer's own application page.
